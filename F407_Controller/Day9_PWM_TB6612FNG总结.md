## 三、PWM 基础

PWM 通过改变一个周期内高电平所占比例来调节驱动输出。

- PWM 频率：`f_pwm = TIMxCLK / ((PSC + 1) × (ARR + 1))`
- 占空比：`Duty ≈ CCR / (ARR + 1) × 100%`

已知系统时钟配置为 SYSCLK = 168 MHz、APB1 分频为 4、PCLK1 = 42 MHz。在 APB1 定时器时钟倍频规则适用时，TIM3 时钟为 84 MHz。

若 `PSC = 83`、`ARR = 999`，PWM 频率约为：

`84 MHz / (84 × 1000) = 1 kHz`

对应比较值：
- `CCR = 200`：约 20% 占空比
- `CCR = 500`：约 50% 占空比
- `CCR = 800`：约 80% 占空比
- `CCR = 0`：0% 占空比

实际频率和占空比以当前 CubeMX 的 TIM3 配置为准。

## 四、核心代码逻辑

### 1. 电机初始化 `Int_Motor_Init()`

初始化顺序：
1. 先无条件将 STBY 拉高（使能驱动器），避免 PWM 启动失败导致 STBY 停留在低电平。
2. 将 AIN1、AIN2 拉低。
3. 调用 `HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_3)` 启动 PWM。
4. 将 TIM3_CH3 的比较值设为 0，避免初始化时立即输出较高占空比。
5. PWM 启动失败时返回 `HAL_ERROR`，成功时返回 `HAL_OK`。

### 2. 设置电机速度 `Int_Motor_SetSpeed(int16_t speed)`

速度输入范围为 `-1000 ~ 1000`：

- 正数：AIN1 = 高、AIN2 = 低，设置一个方向。
- 负数：AIN1 = 低、AIN2 = 高，设置相反方向。
- 0：调用 `Int_Motor_Stop()`。
- 超出范围时限制在 `-1000 ~ 1000`。
- PWM 比较值设为速度绝对值，例如 `500` 代表约 50% 占空比（假设 ARR = 999）。

### 3. 停止电机 `Int_Motor_Stop()`

将 PWM 比较值设为 0，并将 AIN1、AIN2 拉低。实际电机的制动或滑行表现还与 TB6612 状态及模块接线有关；该函数不应被视为独立的硬件急停功能。

## 五、临时测试任务

可以按顺序测试：

1. `Int_Motor_SetSpeed(200)`，运行 2 秒。
2. `Int_Motor_SetSpeed(500)`，运行 2 秒。
3. `Int_Motor_SetSpeed(800)`，运行 2 秒。
4. `Int_Motor_Stop()`，等待 2 秒。
5. `Int_Motor_SetSpeed(-300)`，运行 2 秒。
6. `Int_Motor_Stop()`，等待 2 秒。

CMSIS-RTOS2 工程中，可在 `freertos.c` 定义任务函数，并在 `MX_FREERTOS_Init()` 的线程用户代码区域用 `osThreadNew()` 创建任务。任务函数必须定义在其他函数外部。测试完成后应删除或禁用临时测试任务，避免后续调试时电机自行转动。

## 六、STBY 问题与解决

### 现象

STBY 由 PB14 控制时电机不转；将 TB6612 的 STBY 接到 3.3V 后，电机可以正常运行。

### 原因分析

TB6612FNG 的 STBY 是待机控制输入：低电平会使驱动器进入待机，高电平使驱动器退出待机。直接接 3.3V 后恢复工作，说明此前应重点检查 PB14 的 GPIO 配置、实际接线和初始化调用。

实测排查过程提示：**代码修改后 PB14 仍为 0V，真正的根因是固件没有更新**——Keil 链接阶段报 `L6449E: I/O error writing file 'xxx.o'`，输出窗口出现 `Target not created`，导致 `.hex` 没有重新生成，烧录进去的仍是旧固件。因此判断"改了代码但硬件无变化"时，应优先确认编译是否成功、固件是否已重新烧录。

### 检查项

- CubeMX 中 PB14 配置为 `GPIO_Output`。
- `MX_GPIO_Init()` 在 `Int_Motor_Init()` 之前执行。
- `Int_Motor_Init()` 确实被调用，且返回 `HAL_OK`。
- PB14 物理连接到模块的 STBY 引脚。
- 初始化完成后，PB14 / STBY 电压应接近 3.3V。
- 改线前先断电，避免 STBY 同时连接到 3.3V 和另一个输出低电平的 GPIO。

调试阶段可暂时将 STBY 固定接 3.3V；最终项目建议由 PB14 控制，以便后续实现软件待机、故障处理和系统集成。

## 八、常见问题排查顺序

0. **编译/烧录确认：** 修改代码后务必确认 Keil 输出为 `0 Error`、无 `Target not created`，且已重新 Download。否则烧录的是旧固件，现象不会改变。
1. **电源：** VM 是否接符合电机额定电压和电流要求的电源，VCC 逻辑供电是否正常。
2. **共地：** STM32、TB6612、电机电源是否共地。
3. **STBY：** 是否为高电平，PB14 是否配置为 GPIO 输出。
4. **方向信号：** AIN1/AIN2 是否按预期变化。
5. **PWM：** TIM3_CH3 是否启动；PB0 是否配置为 TIM3_CH3；PSC、ARR、CCR 是否正确。
6. **软件调用：** 初始化函数和测试任务是否执行；检查 `HAL_TIM_PWM_Start()` 返回值。
7. **物理引脚：** 以模块丝印和实际开发板引脚图为准。
